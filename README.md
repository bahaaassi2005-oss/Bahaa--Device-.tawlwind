# 📱 Bahaa Devices

Bahaa Devices is a responsive front-end e-commerce website for smartphones and accessories. The project was built using HTML, Tailwind CSS, and JavaScript as part of a university web development project.

## 🚀 Features

- Responsive design for desktop and mobile
- Home page with hero section
- Browse phones by brand
- Product customization (storage and color)
- Shopping cart using Local Storage
- Special offers page
- Accessories page
- FAQ section
- Contact form
- About page
- Return Policy
- Privacy Policy
- Terms & Conditions

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome

## ▶️ How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Install the Live Server extension.
4. Right-click `index.html`.
5. Select **Open with Live Server**.
